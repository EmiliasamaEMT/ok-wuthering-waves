# mc小帮手 v0.1.0

mc-helper 首个正式版，采用 beta.7 已验收的功能代码。China 和 Global 发行包均从本 fork 获取应用更新。

## 本版内容

- 发行名为 `mc-helper`，界面名称为「mc小帮手」。
- 便携版升级后重新打开可正确识别版本，检查更新时复用已有 Git 数据。
- 原生启动模式可正确比较测试版与正式版，更新按钮和升级识别正常工作。
- 大体积便携包以 7z 分卷发布，并提供下载校验文件。
- 便携模式更新后自动重启；原生启动模式更新后需手动再次启动应用。

## 下载与启动

从 [v0.1.0 发行页](https://github.com/EmiliasamaEMT/ok-wuthering-waves/releases/tag/v0.1.0) 获取文件。首次使用建议下载完整便携包。

1. 下载所选 profile 的全部分卷，例如 China 包的 `.7z.001`、`.7z.002`，放在同一目录。
2. 用 7-Zip 打开 `.001` 解压，建议使用较短目录，例如 `C:\mc-helper`。
3. 便携模式运行 `mc-helper.cmd`；按 Windows 提示确认管理员权限。

`mc-helper-win32.zip` 是原生启动器，不是完整便携环境。`SHA256SUMS` 用于校验下载文件；`win32_sha256.txt` 对应 ZIP 内的原生 EXE。

## 从测试版更新

beta.7 可在「关于」页点击「检查更新」，选择 `v0.1.0` 后更新；正式版本应出现在普通更新列表中，无需勾选「检查测试版」。

旧测试版的原生模式若存在更新按钮不可用的问题，可下载新版完整包使用。保留旧目录和配置备份；用户配置位于 `data/apps/mc-helper/working/configs`。

## 验证范围

China 两种模式均已从 beta.7 实际升级至本正式版，原配置完整保留。便携版通过应用内更新、自动重启及原 CMD 关闭重开；原生版通过启动器升级及手动启动，窗口版本与实际代码一致。Global 已完成云端构建、完整性校验和静态更新源检查。

本次正式发布的构建、下载校验及 beta.7 → v0.1.0 实测结果见 [发行验证记录](https://github.com/EmiliasamaEMT/ok-wuthering-waves/blob/dev/docs/development/github-release-validation.md)。
